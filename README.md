# مشغّلي — مشغّل IPTV (Xtream) للهاتف وتلفزيون أندرويد

قنوات مباشرة، أفلام، مسلسلات، دليل برامج (الآن/التالي)، واجهة عربية.
يعمل على الهاتف والتلفزيون (يدعم الريموت). لا تُحفَظ بياناتك في الكود؛ تُدخلها عند أول تشغيل.

## البناء بدون Android Studio (GitHub Actions)
1. أنشئ حساباً مجانياً في github.com ثم مستودعاً جديداً (Private).
2. ارفع كل ملفات هذا المجلد إلى المستودع (بما فيها مجلد `.github`).
3. من تبويب **Actions** ← **Build APK** ← **Run workflow**.
4. بعد دقائق افتح التشغيل المكتمل ونزّل **MyTv-apk** (ملف app-debug.apk داخل zip).

## البناء بـ Android Studio
افتح المجلد، انتظر مزامنة Gradle، ثم Build ← Build APK(s).

## التثبيت
- الهاتف: انقل الملف وثبّته (اسمح بالتثبيت من مصدر غير معروف).
- تلفزيون شاومي: انسخ الملف بفلاش USB، أو نزّله بتطبيق Downloader، وفعّل "مصادر غير معروفة".

## الإعداد
عند أول تشغيل أدخل: عنوان السيرفر `http://smrtbx.cc` + اسم المستخدم + كلمة المرور.
حقل User-Agent الافتراضي `com.smart.boxtv/53`، ويمكن تغييره من الإعدادات.
عند فشل التشغيل تظهر رسالة فيها رمز رد السيرفر (مثل 403 أو 458) لتحديد السبب.
